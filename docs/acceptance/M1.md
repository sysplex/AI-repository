## 3. 越权矩阵复核（T05 + T06）

| 端点 | 认证方式 | 越权语义 | 用例 |
|---|---|---|---|
| `GET /me` | Bearer | 只能取本人资料 | `_case_get_me` |
| `PATCH /me` | Bearer | 只能改本人设置，且不改到他人 | `_case_patch_me`（含「B 的设置保持默认」副作用断言） |
| `GET /me/usage` | Bearer | `AiUsageRepository` 经 `_scoped()` 强制带 `user_id` | `_case_usage`（预置 B 的 88 次调用，A 只看到自己的 3 次） |
| `GET /admin/users` | Bearer + admin | 角色不足 403，且响应体不含他人信息 | `_case_admin_users` |
| `POST /auth/logout` | Bearer | 不能吊销他人 refresh（提交 B 的 refresh 后 B 仍可刷新） | `_case_logout` |
| `POST /auth/password/reset-request` | 公开 | 无租户维度：账号存在与否都返回同一 202，不发信不落库 | `test_reset_request_hides_account_existence` |
| `POST /auth/password/reset-confirm` | 重置令牌 | 无租户维度：令牌摘要全局唯一且一次性，与 Bearer 租户隔离无关 | `test_reset_token_is_single_use` 等 4 用例 |

结论：Bearer 认证的私有端点共 5 个，矩阵 5 行全覆盖；两个重置端点不属于「私有资源」语义，故未纳入矩阵，T05 的 `expected` 集合同步保持 5 项不变。

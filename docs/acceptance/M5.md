## 3. 架构与安全契约对照（`CONTRACTS.md`）

对照 `docs/tasks/M5/CONTRACTS.md` 与全局工程规范：

1. **商业 SDK 严格外部隔离（Clean Architecture & TID251）**：
   - 商业 LLM SDK 严禁出现在 `adapters/` 以外的任何模块中；
   - 业务层与服务层仅依赖 `ports.LLMClient` 抽象协议；
   - `ruff` 检查配置了 `flake8-tidy-imports`（`TID251`）自动化阻断非法商业 SDK 导入。
2. **Import-Linter 5 项架构分层契约 100% 保持（5 kept, 0 broken）**：
   - `分层契约：api → 应用服务 → 能力模块 → domain → core`: KEPT
   - `独立契约：marketdata / ai / identity 互不依赖`: KEPT
   - `独立契约（续）：marketdata / ai / identity 不依赖其他业务模块`: KEPT
   - `禁止契约：业务模块只能引用对方的 service / schemas 公开面`: KEPT
   - `禁止契约：路由层不得引用业务模块内部面`: KEPT
3. **高精货币与财务计算（High-Precision Decimal Accounting）**：
   - Token 单价、调用开销、预算阈值、指标估值 100% 采用 `Decimal` 类型；
   - 绝对杜绝浮点数（`float`）舍入误差对成本账本或风控熔断产生干扰。
4. **数据库迁移可逆性（Reversible Migration）**：
   - `alembic/versions/0005_ai.py` 完整实现 `upgrade()` 与 `downgrade()`；
   - 包含 `ai_reports`, `ai_usage`, `ai_recommendation_outcomes`, `data_snapshots` 4 张表、枚举类型与高效联合索引，支持安全一键升降级回滚。
5. **HARD-01 安全鉴权与多租户隔离**：
   - 全量 `/api/v1/ai/*` 端点通过 `Depends(current_user)` 鉴权；
   - 用户名下分析报告与输入快照实施强租户隔离，跨用户访问返回 404 NOT_FOUND。

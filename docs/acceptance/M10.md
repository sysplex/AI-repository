## 3. 架构规范与非功能性要求审计

1. **分层契约（Clean Architecture & Import Linter）**：
   - 运行 `lint-imports`：Analyzed 144 files, 468 dependencies. **Contracts: 5 kept, 0 broken**。
   - `scheduler` 与 `notify` 模块严格位于能力服务层，底层依赖 `app.core`（metrics, calendar, logging），对外通过声明式 API 暴露，业务模块间无循环引用。
2. **时区与金融日历合规**：
   - 所有定时与批处理时间均锚定美东时区（`America/New_York`），数据库落库统一转换保存为标准 UTC ISO-8601；
   - 支持跨夏冬令时切换与半日市交易日识别。
3. **高可用与故障静默隔离**：
   - 多渠道投递（Webhook, Email）遇 5xx 或网络超时在 `dispatcher` 内部闭环吸收，保障收盘批处理主流程 100% 顺利走完；
   - Prometheus 业务埋点均受 `contextlib.suppress(Exception)` 保护，在指标未启用或异常时零开销且零业务侵入。
4. **数据库迁移可逆性（Reversible Database Migrations）**：
   - 迁移脚本 `0007_scheduler_notify.py` 严格实现 `upgrade()` 和 `downgrade()`；
   - 经验证 `alembic downgrade -1` 与 `alembic upgrade head` 双向迁移平滑无损。
5. **不可变发布与回滚保证（GEMINI.md）**：
   - Docker 镜像非 root 用户运行（UID 10001）；
   - 预备发布语义化版本 Tag `v1.0.0`，Harbor 双标签归档，支持 Argo CD 与 K8s CLI 秒级一键回滚。

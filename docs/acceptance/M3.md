## 3. 架构契约与合规对照（`CONTRACTS.md`）

对照 `docs/tasks/M3/CONTRACTS.md` 与分层架构规范：

1. **六边形架构与解耦（Hexagonal Ports & Decoupling）**：
   - `strategy` 模块定义 `MarketDataServiceProtocol` 与 `Bar` 协议，不直接强耦合 `marketdata` 的具体数据库实体或模型。
   - 数据服务依赖在 `app/api/router.py` 组合根中由 `get_data_service()` 自动依赖注入到 `StrategyService`，符合整洁架构分层。
2. **防未来函数铁律（Lookahead Bias Free）**：
   - 所有的指标计算函数接收按时间升序排列的历史日线序列。
   - `StrategyService` 与 `BacktestEngine` 在第 $t$ 日仅向策略注入 $s \le t$ 的历史 Bar，严格从物理与逻辑上根除未来函数泄漏。
3. **精度与确定性规范**：
   - 价格、指标计算、止损位、目标位、资金变动、收益率及回撤一律采用高精 `Decimal` 运算，杜绝浮点精度丢失。
   - 所有的领域模型均配置 `model_config = ConfigDict(frozen=True)`，确保策略执行上下文和信号的不可变性。
4. **架构分层契约（Import-Linter 100% 保持）**：
   - `分层契约：api → 应用服务 → 能力模块 → domain → core`: KEPT
   - `独立契约：marketdata / ai / identity 互不依赖`: KEPT
   - `独立契约（续）：marketdata / ai / identity 不依赖其他业务模块`: KEPT
   - `禁止契约：业务模块只能引用对方的 service / schemas 公开面`: KEPT
   - `禁止契约：路由层不得引用业务模块内部面`: KEPT
5. **HARD-01 安全鉴权规范**：
   - 策略端点 `/api/v1/strategy/*` 全部通过 `Depends(current_user)` 鉴权门禁，未授权或过期令牌统一拦截返回 401 UNAUTHENTICATED。

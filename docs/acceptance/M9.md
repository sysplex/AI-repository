## 3. 架构与安全契约对照（`CONTRACTS.md`）

对照 [`docs/tasks/M9/CONTRACTS.md`](../tasks/M9/CONTRACTS.md) 与全局规范要求：

1. **类型零漂移（Zero Type Drift）**：
   - 前端所有 API 请求体与响应体统一由 OpenAPI Generator 自动化导出；
   - 杜绝任意手写 DTO，彻底解决前后端字段重命名或可选性变更导致的隐式 Bug。
2. **强制金融合规三要素（Compliance Guardrails 100% 植入）**：
   - **法定免责声明（Legal Disclaimer）**：固定文案 `"本内容仅供研究与模拟学习，不构成任何投资建议。市场有风险，投资需谨慎。"`，存在于所有 AI 研报、买入决策、主题卡片与模拟盘控制台底部。
   - **数据新鲜度标签（Data Freshness）**：明确标注 `"数据截至: YYYY-MM-DD HH:mm:ss (EST)"`；当数据陈旧（`stale=true`）时强制呈现黄/橙色 `[数据可能延迟]` 警告徽章。
   - **AI 引擎与提示词模板版本 Badge**：所有 AI 研报卡片显式标注 `"AI 引擎: gpt-4o | 模板: v1.0.0"`，满足全流程合规审计要求。
3. **统一异常响应拦截与友好降级**：
   - `401 UNAUTHENTICATED`: 拦截器触发无感刷新，失效时重定向至 `/login`；
   - `429 QUOTA_EXCEEDED`: 友好弹出拦截提示（`"今日 AI 配额已达上限，请明日重试或联系管理员"`）；
   - `503 BUDGET_CIRCUIT_OPEN`: 友好弹出系统熔断提示（`"服务熔断保护已触发，请稍后重试"`）；
   - 409 状态冲突（如自选重复添加）：友好提示用户标的已存在，防止界面卡死。
4. **金融数值精度与色彩偏好**：
   - 价格格式化：美股默认保留 2 位小数，分厘股 4 位；
   - 百分比格式化：统一带符号 `+X.XX%` / `-X.XX%`；
   - 涨跌偏好：默认国际标准（绿涨红跌），支持用户一键切换国内习惯（红涨绿跌）。

## 5. 容器化构建与运维部署规范

根据 `GEMINI.md` 规则与交付清单要求，完成前端轻量化容器打包：

1. **多阶段 Docker 构建 (`frontend/Dockerfile`)**：
   - 构建阶段：基于 `node:20-alpine`，仅安装依赖并执行 `npm run build` 生成优化后的静态资源；
   - 运行阶段：基于 `nginx:1.27-alpine`，仅携带生产静态资产与轻量 Nginx 配置文件，不含源码、devDependencies 与测试文件。
2. **非 root 安全基线**：
   - 固定运行用户为 `appuser`（UID 10001，GID 10001），杜绝 root 权限运行；
   - Nginx pid、cache 与 log 目录权限严格授予 UID 10001；
   - 监听非特权端口 `8080`。
3. **Nginx SPA 生产反向代理 (`frontend/nginx.conf`)**：
   - 静态资源支持 Gzip 动态压缩（text, json, js, css, svg）；
   - 安全标头：`X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `Referrer-Policy: no-referrer`；
   - 后端路由转发：`/api/` 自动转发至后端服务 `http://stockpilot_api`；
   - 单页应用回退：`try_files $uri $uri/ /index.html;` 支持客户端 React Router 深度链接刷新不 404；
   - 存活探针：`/healthz` 返回 HTTP 200。

# 01 需求说明（PRD）

## 1. 目标

构建一个美股 AI 辅助研究与**模拟交易**系统：实时（准实时）获取市场数据，用代码规则筛选股票，用 AI 以"专业分析师"身份解读，并通过模拟盘验证决策，最终用数据检验 AI 建议的真实质量。

## 2. 核心原则

1. **数据由代码取，AI 只解读**：所有数字来自数据源，AI 不得凭记忆给数字。
2. **筛选用规则，不用 AI 在全市场选股**：可复现、可回测。
3. **一切可复盘**：每份 AI 报告留存数据快照、提示词版本、模型版本。
4. **可扩展**：外部依赖全部在接口（端口）后面。
5. **多租户就绪**：所有用户数据带 `user_id`，权限在服务层强制校验。

## 3. 范围

### 3.1 范围内（v1）
九大功能（见 §4）、用户体系、Web 界面、模拟盘、定时任务、通知。

### 3.2 非目标（v1 不做）
- 真实资金下单（仅接口预留 `Broker` 端口）
- 期权、期货、加密货币、非美股市场
- 高频/日内毫秒级策略
- 移动端原生 App（响应式网页即可）
- 社交/跟单功能

## 4. 功能需求与用户故事

| ID | 功能 | 用户故事 | 对应模块 |
|---|---|---|---|
| F1 | 模拟盘 | 作为用户，我能创建虚拟账户、买入卖出，看到持仓、已实现/未实现盈亏、净值曲线 | M4 |
| F2 | 股票研究 | 输入代码，得到商业模式、收入来源、护城河、风险、近期表现、债务、利润、增长，以及看涨/看跌/中立三段总结，语言通俗 | M6 |
| F3 | 买入决策 | 输入想买价、持有期、风险承受度，得到 买/等/避开 + 理由，涵盖估值、盈利增长、行业、新闻、分析师、下行风险 | M6 |
| F4 | 股票对比 | 输入多只股票，得到按增长、利润率、债务、估值、竞争力、风险、分红、前景的评分排名，及各自适合的投资者 | M7 |
| F5 | 长期持有 | 评估 5/10/15 年可持有性：护城河、管理层、需求、提价权、创新、财务、市场空间；给出论文与"论文破裂条件" | M7 |
| F6 | 技术面分析 | 趋势、支撑压力、均线、量能、RSI、MACD、突破；给出进场、止损、目标（数值由代码计算） | M3 + M6 |
| F7 | 财报解读 | 汇总最新财报：收入、EPS、利润率、指引、管理层评论、市场反应；判断强弱及短长期走势 | M6 |
| F8 | 组合配置 | 输入资金、候选股、风险偏好、目标，输出配比、理由、现金比例（数值由代码优化后 AI 解释） | M7 |
| F9 | 主题自选 | 按主题（AI、分红、医疗、能源、低估值、成长…）给出股票清单与新手说明 | M8 |
| F10 | 策略筛选 | 选预设策略，从股票池筛出候选，一键送入研究/对比 | M3 + M8 |
| F11 | 用户体系 | 注册登录、数据隔离、配额 | M1 |
| F12 | 提醒与日报 | 价格/信号/财报日提醒，每日报告推送 | M10 |
| F13 | AI 建议复盘 | 统计历史 AI 建议的后续表现 | M10 |
| F14 | 交易日志 | 每笔模拟交易附理由，可复盘 | M4/M9 |

## 5. 非功能需求

| 类别 | 指标（初值，可调整） |
|---|---|
| 性能 | 缓存命中的行情接口 P95 < 300ms；AI 分析异步，P95 < 90s |
| 可用性 | 数据源失败时降级（用缓存并标注"数据时间"），不让 AI 在缺数据时作答 |
| 安全 | 见 07 文档第 6 节 |
| 成本 | 每用户每日 AI 调用上限；单次调用成本入库；全局日预算熔断 |
| 可维护 | 模块边界由工具强制（import-linter），覆盖率 ≥ 80% |
| 可观测 | 结构化日志、请求 ID 贯穿、关键指标（调用量、失败率、AI 成本） |
| 国际化 | v1 中文界面与中文 AI 输出；文案与提示词语言可配置 |

## 6. 约束与假设

- 数据延迟：v1 允许 15 分钟延迟或日线级别，界面标注数据时间。
- 模拟盘信号收盘后产生，次日开盘价成交（防未来函数）。
- 时区：存储 UTC，业务逻辑用 `America/New_York` 与 NYSE 日历。

## 7. 风险登记

| 风险 | 影响 | 缓解 |
|---|---|---|
| 数据源不稳定/授权受限 | 功能不可用、法律风险 | `DataProvider` 端口、缓存、开放前换授权源 |
| AI 编造数据 | 误导用户 | 结构化输入、Schema 校验、数字溯源校验 |
| AI 成本失控 | 费用 | 缓存、配额、熔断、成本监控 |
| 范围蔓延 | 延期 | 按模块验收，v1 非目标清单 |
| 合规 | 法律 | 免责声明、仅研究/模拟、上线前专业咨询 |
